Estándar

Alepo busca que este sitio web cumpla el nivel AA de las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.2.

  • Cada página se puede usar con el teclado, y el foco siempre es visible.
  • El texto y los controles cumplen las relaciones de contraste del nivel AA.
  • Las imágenes tienen texto alternativo.
  • El movimiento se detiene para quienes piden movimiento reducido en su dispositivo.
  • Los encabezados, las regiones y las etiquetas están preparados para lectores de pantalla.

Cómo se revisó

Cada página se revisó con pruebas automáticas en noviembre de 2026. Los menús, las pestañas, las preguntas y el cambio de idioma también se revisaron con el teclado. Las pruebas automáticas no detectan todas las barreras, así que avísenos si encuentra una.

Límites conocidos

Las publicaciones del blog, las noticias y las páginas de la biblioteca vienen del sitio web anterior y es posible que aún no cumplan el mismo estándar.

Comentarios

Si algo en este sitio web no le funciona, avísenos desde la página de contacto.
