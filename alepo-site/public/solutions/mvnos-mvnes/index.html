What is an MVNE?

An MVNE (mobile virtual network enabler) provides the systems an MVNO needs to run: charging, billing, provisioning and often the core network connection to the host operator. One MVNE can host many MVNO brands, each with its own plans and customers.

An MVNO owns the brand and the customer. Behind it, an MVNE runs the technology. The host operator owns the radio network.

Common questions

What is the difference between an MVNO and an MVNE?

An MVNO sells mobile service under its own brand. An MVNE provides the platform that MVNOs run on, including charging, billing and provisioning.

What does an MVNO platform include?

An MVNO platform covers self-care, CRM, billing, real-time charging and sales channels. You get these together as BSS in a Box.

Can one MVNE host several brands on Alepo?

Yes. Each brand runs on its own deployment, and settlement handles each brand separately.
