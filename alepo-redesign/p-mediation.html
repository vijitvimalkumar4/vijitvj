Products/BSS and monetization/Mediation Studio

Mediation Studio

Collects and cleans every usage record from the network before billing, and shows that nothing was lost or double-counted.

Request a demo
OverviewCapabilitiesAIQuestions

Overview

Mediation Studio collects and cleans every usage record from the network before billing. A ledger per file shows what the network sent and what billing received.

Revenue leaks through lost, duplicated or stuck usage records. There is no per-file evidence when billing is disputed, and every new feed becomes a services project.

Works withSwitches, the packet core, AAA and other network sources. Billing, settlement and the data warehouse downstream.
DeliveryOn premises or SaaS, with 24x7 support
Also known asmediation, billing mediation, CDR mediation, xDR mediation, Mediator, usage data collection.

Duplicate detection

Duplicate records are detected. Failed records are repaired and resubmitted.

A gap or a duplicate in a file sequence is found before billing.

Balancing ledger

A balancing ledger per file shows what the network sent and what billing received.

When a bill is disputed, there is evidence for each file.

Data masking

Personal data is masked at delivery.

Sources include switches, the packet core and AAA. Billing, settlement and the data warehouse receive the output.

AI in Mediation Studio

The Mediation Studio agent watches around the clock. When something looks wrong, it brings your team the finding and a proposed next step.

Staff ask a question in the Mediation Studio console. AI Assist answers from live data and suggests the next step.
